# TrackRecord

Track record de trading et suivi de patrimoine.

**Télécharger pour Windows :** [TrackRecord-Setup.exe](https://github.com/Teeroo/Trackrecord/releases/latest/download/TrackRecord-Setup.exe)

Double-cliquer sur le fichier, c'est installé. L'application se met ensuite à jour toute seule.
Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*.
